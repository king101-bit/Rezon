# Rezon

Browse details about your favorite movies and shows, and get recommendations for new ones to watch. Powered by the [TMDB API](https://www.themoviedb.org/).

I'm building this as a Seerr alternative for myself, since Seerr doesn't work for me. :(

Built with Next.js and Tailwind CSS.
